Falta só um passinho 💚

Para o app funcionar, é preciso colar as credenciais do seu projeto Firebase no objeto firebaseConfig, lá no topo do <script type="module"> deste arquivo.

  1. Crie um projeto em console.firebase.google.com
  2. Ative Authentication → Anonymous
  3. Crie o Firestore Database em modo produção
  4. Copie as credenciais em Configurações do Projeto → Seus apps → Web
  5. Cole no firebaseConfig e recarregue
